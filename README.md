# Умная доска · экспонат 08

Полноценный локальный прототип музейного экспоната: посетитель пишет функцию пером, получает OCR-кандидат, вручную подтверждает запись и исследует график с помощью коэффициентов.

## Что реализовано

- рукописный холст с Pointer Events, поддержкой пера, касания и мыши;
- отмена штриха, очистка, защита от устаревших OCR-ответов;
- три готовых эксперимента: прямая, парабола и гипербола;
- настоящий локальный OCR-адаптер для Ollama и `qwen2.5vl:3b`;
- редактирование и **обязательное подтверждение** распознанной записи;
- безопасный разбор формулы через белый список Python AST без `eval`, `sympify` и `parse_expr`;
- расчёт 401 точки через SymPy, отображение разрывов области определения;
- интерактивный Canvas-график, координаты при наведении, ползунки `a`, `b`, `c`;
- адаптивный киоск-интерфейс, полноэкранный режим и клавиатурное управление;
- health/doctor-диагностика, security headers и автоматические тесты API.

OCR не подменяется фиктивным результатом: если Ollama или модель недоступны, интерфейс явно сообщает об этом. Готовые шаблоны и ручной ввод остаются рабочими.

## Быстрый запуск на Windows

Требуется Python 3.12 x64.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py --self-test
.\.venv\Scripts\python.exe app.py
```

Откройте <http://127.0.0.1:8018> в Chrome или Edge. Для музейного режима нажмите кнопку полноэкранного просмотра в правом верхнем углу.

### Linux / macOS

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py --self-test
.venv/bin/python app.py
```

## Подключение OCR

1. Установите [Ollama](https://ollama.com/).
2. Загрузите vision-модель:

   ```powershell
   ollama pull qwen2.5vl:3b
   ```

3. Проверьте соединение:

   ```powershell
   .\.venv\Scripts\python.exe app.py --doctor
   ```

Успешная диагностика выводит `"available": true`, `"model_ready": true` и фактический digest модели. Интерфейс обращается только к `127.0.0.1`; изображение рукописи не отправляется во внешнее облако.

Можно изменить адрес и модель переменными окружения:

```powershell
$env:OLLAMA_URL = "http://127.0.0.1:11434"
$env:OLLAMA_MODEL = "qwen2.5vl:3b"
$env:OLLAMA_TIMEOUT_SECONDS = "120"
$env:OLLAMA_KEEP_ALIVE = "30m"
.\.venv\Scripts\python.exe app.py
```

Первое распознавание после запуска Ollama может занять до минуты, пока модель загружается в память. По умолчанию доска ждёт ответ до 120 секунд и оставляет модель загруженной на 30 минут; следующие запросы обычно выполняются заметно быстрее.

## Запуск двойным щелчком

После однократной установки зависимостей можно запускать `START-BOARD.cmd`. Скрипт проверяет `.venv`, при необходимости запускает Ollama, открывает браузер и оставляет сервер в рабочем окне. Для остановки нажмите `Ctrl+C` в этом окне.

## Проверки

Быстрый встроенный smoke-test:

```powershell
.\.venv\Scripts\python.exe app.py --self-test
```

Полный набор unit- и HTTP-тестов:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверяются:

- контрольные значения всех трёх шаблонов;
- коэффициенты в диапазоне `−10…10`;
- `null` в точке разрыва `1/x`;
- обязательное подтверждение;
- отказ вызовам, атрибутам, коллекциям и произвольному Python-коду;
- PNG-границы OCR;
- HTTP-контракты и защитные заголовки.

## Поддерживаемая математика

Допустимы переменные `x`, `a`, `b`, `c`, конечные числа и операции `+`, `-`, `*`, `/`, степени от `−2` до `4`. Можно вводить привычные варианты `y = x²`, `×`, `÷`, `^` — сервер нормализует их до безопасного синтаксиса.

Примеры:

```text
y = a*x+b
y = a*x^2+b*x+c
y = a/(x-b)+c
```

Не поддерживаются вызовы функций (`sin(x)`), атрибуты, интегралы, коллекции и любой Python-код. Ограничение соответствует задаче экспоната с тремя математическими шаблонами.

## HTTP API

### `POST /api/recognize`

```json
{
  "request_id": "ocr-1",
  "image_base64": "...PNG без data URL prefix..."
}
```

Ответ всегда содержит `confirmed: false`. Максимальный PNG — 1 МиБ.

### `POST /api/plot`

```json
{
  "request_id": "plot-1",
  "formula": "a*x**2+b*x+c",
  "confirmed": true,
  "coefficients": { "a": 1, "b": 0, "c": 0 }
}
```

Возвращаются 401 точка на `x ∈ [−10, 10]`. Неопределённые значения передаются как `null`.

### Диагностика

- `GET /api/health` — сервер, SymPy, шаблоны;
- `GET /api/ocr-status` — доступность Ollama, модели и digest;
- `python app.py --doctor` — та же OCR-проверка из терминала.

## Оборудование

Графический планшет или ИК-рамка должны передавать перо браузеру как стандартные Pointer Events. Перед выставкой проверьте четыре угла холста, центр, непрерывность линии и системное масштабирование дисплея. Для Windows при необходимости установите драйвер производителя планшета.

Качество `qwen2.5vl:3b` на конкретном почерке и скорость на музейном ПК нужно измерить отдельно на наборе минимум из десяти формул. Физическое устройство и OCR-модель не могут считаться проверенными только по программным тестам.
