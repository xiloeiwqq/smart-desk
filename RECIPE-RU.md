# 08 · Умная доска: рукопись, подтверждение и безопасное вычисление

Рабочий локальный холст, ручное подтверждение, три математических шаблона, график и настоящий HTTP-адаптер локального OCR через Ollama. Модель OCR не загружалась и её качество на рукописи не измерено. В тесте график рисуется Canvas, а не Plotly.

Документация и первые испытания · 15 ноября 2026

## Что проверено

| Проверка | Результат | Граница |
| --- | --- | --- |
| Python 3.12.14 / SymPy 1.14.0 | PASS контрольных точек трёх шаблонов, коэффициентов, null при 1/x, подтверждения и отказа опасному AST | Без физического пера и без OCR-модели. |
| OCR/драйвер планшета/браузер | Не проверено | Нужны установленная модель, реальные рукописные образцы и устройство ввода. |

## Соединения и обмен данными

| Откуда | Куда | Контракт | Проверка |
| --- | --- | --- | --- |
| USB-планшет → браузер | canvas#write | Pointer Events; координаты пересчитываются из CSS в 1200×360; PNG base64 | Десять контрольных точек и непрерывная линия отображаются без сдвига. |
| Холст → сервер доски | POST http://127.0.0.1:8018/recognize | JSON {request_id,image_base64}; PNG до 1 MiB; возвращает candidate, confirmed:false | Старый request_id после нового штриха не перезаписывает текущую формулу. |
| Сервер → Ollama | POST http://127.0.0.1:11434/api/generate | model=qwen2.5vl:3b, images=[base64], format=json, stream=false; ожидается response со строкой JSON {formula} | При отсутствии сервиса явный OLLAMA_UNAVAILABLE, без подстановки выдуманного распознавания. |
| Подтверждённая формула → математика | POST /plot | JSON {request_id,formula,confirmed:true,coefficients:{a,b,c}}; только x/a/b/c и + - * / степени -2..4 | Без подтверждения возвращается ошибка; вызовы функций/атрибуты/Python-код отклоняются. |
| SymPy → график | Ответ /plot → Canvas | 401 точка x от -10 до 10; y=null обозначает разрыв области определения; коэффициенты -10..10 | Для 1/x центральная точка null; график не соединяет разрыв одной линией. |

## Установка

### 1. Windows PowerShell: создать отдельный Python venv

Установить Python 3.12 x64 с Windows launcher py. Открыть PowerShell в папке распакованного проекта. Далее pip и программы запускаются явно через .\.venv\Scripts\python.exe: активация и изменение ExecutionPolicy не нужны. Если команда завершилась ошибкой, сначала устранить её; следующий этап не считается выполненным.

```text
$ErrorActionPreference = 'Stop'
py -3.12 --version
if ($LASTEXITCODE -ne 0) { throw "Install Python 3.12 with the Windows py launcher before continuing" }
py -3.12 -m venv .venv
if ($LASTEXITCODE -ne 0) { throw "Virtual environment creation failed" }
.\.venv\Scripts\python.exe --version
if ($LASTEXITCODE -ne 0) { throw "The virtual environment Python is unavailable" }
```

### 2. Windows: установить математику в этот venv

Установка происходит в созданное окружение. Сеть/PyPI не считаются доступными заранее: при ошибке pip блок останавливается. Код рассчитан на SymPy 1.14.0.

```text
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
if ($LASTEXITCODE -ne 0) { throw "SymPy installation failed; do not start the board until requirements install succeeds" }
```

### 3. Проверить вычислительный модуль

Проверяет контрольные значения трёх шаблонов, коэффициенты, разрыв 1/x, обязательное подтверждение и запрет выполнения кода.

```text
.\.venv\Scripts\python.exe .\app.py --self-test
if ($LASTEXITCODE -ne 0) { throw "Math test failed" }
```

### 4. Запустить локальный интерфейс

Открыть http://127.0.0.1:8018. Ручной ввод работает без OCR; отсутствие модели показывается как ошибка, не как успех.

```text
.\.venv\Scripts\python.exe .\app.py
```

### 5. Подключить настоящий OCR

Windows PowerShell. Установить Ollama с официального сайта и запустить его локальный сервис. Для qwen2.5vl требуется минимум 0.7.0. Успех pull и наличие digest проверяются здесь, а точность рукописи — отдельным испытанием. При недоступной сети/модели остановиться; ручной ввод не является успешным OCR.

```text
ollama --version
if ($LASTEXITCODE -ne 0) { throw "Ollama executable is missing" }
ollama pull qwen2.5vl:3b
if ($LASTEXITCODE -ne 0) { throw "OCR model pull failed; network/model access is unconfirmed" }
.\.venv\Scripts\python.exe .\app.py --doctor
if ($LASTEXITCODE -ne 0) { throw "OCR model/service is absent; do not mark OCR ready" }
```

### 6. Снять метрики

Для каждой PNG сохранить эталон, candidate, исправленный текст, время ответа и наличие ошибок степеней/знаков. Низкая точность означает, что модель или объём распознаваемых формул нужно менять до интеграции в экспонат.

### 7. Linux: отдельная альтернатива для математики

Только Linux: команды используют venv/bin/python и не предназначены для PowerShell. Ollama/OCR устанавливаются и проверяются отдельно; эта последовательность сама не подтверждает OCR.

```text
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py --self-test
.venv/bin/python app.py
```

## Первые три запуска

### 1. Проверить графики на ручном вводе

Установить SymPy, запустить self-test; затем открыть интерфейс, выбрать квадратичную формулу, подтвердить и построить график.

```text
.\.venv\Scripts\python.exe app.py --self-test
if ($LASTEXITCODE -ne 0) { throw "Diagnostic step failed; read the error before proceeding" }
```

Ожидаем: PASS математических проверок. Для a=1,b=0,c=0 у x=2 получается 4; для 1/x при x=0 разрыв.

При ошибке: Если формула без подтверждения строится или __import__ проходит — остановиться и исправить границу ввода. Предлагаемый исходник эти случаи отклоняет.

### 2. Соединить перо и настоящий OCR

Подключить планшет, проверить углы холста. Установить Ollama и модель, запустить doctor. Записать десять формул, нажать распознавание, сверить кандидата и вручную подтвердить.

```text
.\.venv\Scripts\python.exe app.py --doctor
if ($LASTEXITCODE -ne 0) { throw "Diagnostic step failed; read the error before proceeding" }
```

Ожидаем: Сохранён digest модели и таблица из десяти PNG/кандидатов/эталонов/задержек. При ошибке посетитель может исправить запись до построения.

При ошибке: При OLLAMA_UNAVAILABLE проверить :11434. Если модель есть, но знаки и степени читаются неверно, не переносить такую связку в демонстрацию; ограничить шаблоны или заменить OCR после повторного теста.

### 3. Проверить совместную работу и сброс

Прогнать linear/quadratic/inverse, изменить a/b/c, быстро сменить формулу во время OCR. Выполнить очистку, повторить с другим почерком и проверить крайние значения ползунков.

```text
.\.venv\Scripts\python.exe app.py
if ($LASTEXITCODE -ne 0) { throw "Diagnostic step failed; read the error before proceeding" }
```

Ожидаем: Устаревшие ответы не меняют новый ввод; смена выражения снимает подтверждение; ползунки пересчитывают контрольные точки; разрывы видны.

При ошибке: Если после очистки приходит прежняя формула — проверить request_id/epoch. Если коэффициенты вне диапазона или выражение не поддержано — сервер возвращает ошибку для исправления ввода.

## Диагностика

| Симптом | Проверка | Действие |
| --- | --- | --- |
| Перо рисует со сдвигом | Сопоставить реальные размеры canvas и CSS, проверить четыре угла и центр | Отключить лишнее масштабирование драйвера/экрана; исправить калибровку до OCR. |
| Нет распознавания | .\.venv\Scripts\python.exe app.py --doctor: наличие Ollama и digest qwen2.5vl:3b | Запустить сервис Ollama, выполнить pull нужного тега, повторить doctor; не подменять candidate ручным текстом под видом OCR. |
| Распознан неверный минус/степень | Сравнить исходный PNG и candidate, записать время/пример | Исправить запись вручную, оставить confirmed=false до проверки; пополнить контрольный набор. |
| Формула отклонена | Сверить разрешённые переменные, операции, длину <=120, число AST узлов <=64 | Использовать один из трёх шаблонов. Тригонометрия, интегралы, вызовы функций и произвольный Python не поддержаны. |
| На графике пропуск | Проверить знаменатель при конкретном x | Для деления на ноль это ожидаемый null; задача интерфейса — показать разрыв и сохранить возможность нового ввода. |

## До полной сборки

- OCR через qwen2.5vl:3b — конкретная проверяемая гипотеза, не доказанная пригодность для рукописи. Модель не запускалась в этой среде.
- Ручной ввод и Canvas позволяют проверить математический и интерфейсный стык отдельно; это не результат распознавания.
- Физический планшет, браузерная отрисовка и задержка на музейном ПК требуют испытания.
- Шаблоны ограничены linear/quadratic/inverse, диапазон x [-10,10], коэффициенты [-10,10]. Расширение грамматики требует новых математических контрольных случаев.
- В паспортном стеке для данного стенда Plotly заменяется встроенным Canvas 2D; в полной версии его можно вернуть с отдельной проверкой локального JS-пакета.
- Windows PowerShell-команды подготовлены и сверены с путями исходников, но в Linux-среде проверки не исполнялись. Сохранённые PASS-логи относятся только к указанным там фактическим тестам; скачивание моделей и установка внешних пакетов не объявляются подтверждёнными.
